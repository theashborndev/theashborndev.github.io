Arrow Bird Escape · boss levels

The ten dragons and how they break free

Every 100th level is a dragon boss. Each clip below is rendered from the game's own dragon drawing code with the same timings the board uses. The cage size is the real one for that boss.

  • 0.0sCaged: bobbing, blinking, smoke puffs
  • 0.5–1.5sChains snap at 25%, 50%, 75% of arrows cleared
  • 2.2sPadlock drops on the last arrow
  • 2.5sCage bursts, board shakes
  • 2.85sRoar with breath
  • 3.95sFlies off the top
In the game the chains break as you clear arrows, so the caged part lasts the whole level. The clips shorten that to two seconds. The board shakes and sparks fly from the cage, and the roar sound plays. None of that is shown here.
